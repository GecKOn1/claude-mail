Privacy policy – Claude Mail

Last updated: 28 September 2026

Claude Mail is a personal tool used only by its owner to access the owner's own Google accounts.

  • Data accessed: Gmail messages and Google Drive files of the owner's own accounts, only when the owner requests it.
  • Storage: OAuth tokens are stored only on the owner's own computer. No data is stored on any server operated by this app.
  • Sharing: No data is sold, shared with third parties, or used for advertising.
  • Revoking access: Access can be revoked at any time at myaccount.google.com/connections.

Google user data is handled in accordance with the Google API Services User Data Policy, including the Limited Use requirements.
